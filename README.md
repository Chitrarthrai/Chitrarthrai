*Next.js 14 • React Native (Expo) • TypeScript • Tailwind CSS • Supabase Realtime • WebRTC • Zustand*

*React.js • React Native • TypeScript • Supabase Realtime • PostgreSQL • Gemini AI (NER) • Kotlin Native Module • Recharts*

> **Intelligent personal finance & task management system** with sub-100ms cross-platform WebSocket sync. Features a custom Android Kotlin Native Module for offline background SMS parsing combined with zero-shot Gemini AI NER to extract bank transactions and deadlines with 95% accuracy.
